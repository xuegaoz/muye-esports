牧野电竞 · 手机优化分类版 V3
===========================

这版保留手机加载优化，同时恢复“强分类”结构。

1. 基础价目表
2. 趣味单
3. 牧野の一日一签

点击目录后，才显示该分类里的价目表，不再把全部内容混在一起。
