牧野电竞 · GitHub Pages 部署说明
================================

这个文件夹已经整理为 GitHub Pages 可直接部署结构。
请把“本文件夹里面的内容”上传到仓库根目录，不要再套一层文件夹。

仓库根目录应直接看到：
- index.html
- styles.css
- app.js
- data.js
- images/
- .nojekyll

推荐部署方式：
1. GitHub 新建一个仓库，例如：muye-pricebook
2. 将本文件夹内全部文件上传到仓库根目录
3. 仓库 -> Settings -> Pages
4. Build and deployment:
   Source: Deploy from a branch
   Branch: main
   Folder: /(root)
5. Save
6. 部署成功后，页面里会出现 Visit site

网址通常为：
https://你的GitHub用户名.github.io/muye-pricebook/

如果仓库名直接创建为：
你的GitHub用户名.github.io
那么网址就是：
https://你的GitHub用户名.github.io/

后续更新价目表：
- 只更新已有图片：用同名新图片覆盖旧图片，然后 Commit changes
- 新增价目表：上传新图片，并在 data.js 对应分类里新增一项，然后 Commit changes
- 推送到发布分支后 GitHub Pages 会重新发布
