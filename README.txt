牧野电竞 · 在线价目册 V1
==========================

【打开网页】
直接双击 index.html 即可。
如果手机或某些浏览器限制本地 JS，可把整个文件夹部署到任意静态网页托管平台。

【更新旧图片】
1. 找到 images 下对应分类文件夹：
   basic    = 基础价目表
   fun      = 趣味单
   fortune  = 牧野の一日一签
   rules    = 下单须知
2. 用新图覆盖旧图，保持文件名不变。
3. 刷新网页。

【新增价目表】
1. 把图片放进对应 images 文件夹。
2. 打开 data.js。
3. 在对应分类 items: [ ] 中复制一组：
   {
     title: "你的标题",
     image: "images/fun/your-image.jpg",
     description: "一句简短说明"
   }
4. 保存并刷新网页。

【推荐】
- 图片尽量使用 jpg / png / webp。
- 文件名建议英文、小写、用短横线连接，例如 wedding-2026.jpg。
- 修改 data.js 时注意：每一项之间要有英文逗号 , 。
