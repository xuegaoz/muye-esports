牧野电竞 · 手机优先版 V5
=========================

本次重点：
1. 修复“高清图片加载中”不会消失的问题。
2. UI 改为真正 Mobile First：网站最大宽度 560px，电脑打开也保持手机阅读比例。
3. 首页 2×2 四分类目录：
   - 基础价目表
   - 趣味单
   - 牧野の一日一签
   - 下单须知
4. 增加底部四分类导航，更适合手机拇指操作。
5. 分类内改为单列横向卡片，不再使用偏电脑的多列网格。
6. 高清图采用全屏查看方式，不再使用桌面弹窗。
7. 顶部使用牧野电竞现有 Logo。
8. 保留 full / thumbs 手机轻量图片结构。

GitHub 更新方式：
直接把本压缩包中的以下内容上传仓库根目录并覆盖旧文件：
- index.html
- styles.css
- app.js
- data.js
- .nojekyll
- assets/
- images/

如果你已经有 V4 的 images 文件，也建议本次直接用 V5 整包覆盖，避免版本混用。
